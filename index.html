Firm quotes

Price-or-fail, before a transaction exists

Hand back a quoteId and the engine replays that exact route. Add "firm": true inside the window and slippage collapses to a fixed margin — if the market moved past it you get a 409, not a signed transaction that reverts on chain.

Start for free How firm quotes work
  • Ed25519-signed quotes — verifiable without trusting the server
  • Route pinned by quoteId — no silent re-route between quote and swap
  • Failures before signing — your user never pays for a revert

Streaming

Quotes pushed the moment pools move

Subscribe to pairs over one WebSocket and get a fresh quote whenever the pools behind it change — plus an invalidate when a firm quote drifts, so a UI can grey out a stale price before anyone clicks.

See plans with streaming Stream reference
  • Push on pool change — not a poll on a timer
  • Many pairs, one connection — subscribe and unsubscribe as users browse
  • Included from Starter — connections are counted per account
