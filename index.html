The API

Three endpoints carry all the traffic.

Use /swap when you want the fast path. Use /instructions when you need to wrap the swap inside something larger — creating token accounts, attaching a memo, composing it into a liquidation.

GET /api/v1/quote

Price discovery

What will I get, and what will it cost. An in-memory read — nothing in this path touches RPC.

POST /api/v1/swap

A signed-ready transaction

Built server-side against the exact route you were quoted, with min-out anchored to that price.

POST /api/v1/instructions

Raw instructions

Compose the transaction yourself. /cpi/route-accounts returns the account list if you are calling from another program.

Firm quotes

Price-or-fail, before a transaction exists.

Every quote carries a quoteId. Hand it back and the engine replays that exact route rather than re-routing against whatever the book looks like a second later.

Add "firm": true inside the window and slippage collapses to a fixed margin. If the market moved past it you get a 409 — not a signed transaction that reverts on chain.

Quotes are Ed25519-signed. The verification key is public, so a quote can be checked by someone who does not trust the server that issued it.

Ingestion

State that is current to the slot, not to the last refresh.

The engine consumes account updates as the chain produces them and keeps pool state in memory. Nothing in the quote path polls, and nothing in it calls RPC — a quote reads state that is current to the slot rather than to whenever the last refresh happened.

The watched set covers every pool and the accounts behind it, tick arrays and vaults included, so a quote is never priced off a partial book. No state is silently missed.

Fees

You keep every basis point you charge.

Two independent rates on every swap. They add — yours is not a share of ours, and ours does not shrink when you raise yours. Their sum is capped at 100 bps, enforced both on-chain and in the API, so an over-cap request comes back as a 400 rather than as a transaction that fails after your user has signed it.

Every quote, swap, instruction set and CPI account list reports both rates separately — because one blended number cannot tell you what you earned.

Rate limits

Debited by what a request costs, not how many you made.

Your bucket is charged per the table on the right, so the same budget is many quotes, or a few transaction builds, or any mix. Start keyless — about 1 unit per second, burst 5, enough to hold a live price on screen. A key raises it to [YOUR KEYED LIMIT].

Deliberately flat within a tier. A ceiling derived from trailing volume cannot be capacity-planned against, and it throttles a new integration hardest on day one — exactly when its quote-to-swap ratio is at its worst.

Self-hosting

One binary. No CGO, no database in the request path.

Supply an RPC endpoint with Yellowstone gRPC access; everything else is in the image. Self-hosting changes who runs the engine — it does not change the on-chain fee model, because the protocol fee is collected by the program, not by the API.
